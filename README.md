# PDF PASSWORD CRACKING LAB — JOHN THE RIPPER (JTR)

**Project Category:** Cybersecurity | Ethical Hacking | Password Security | File Security  
**Training Platform:** Networkwalks  
**Tools Used:** John the Ripper (JTR) | Hash Generator | Networkwalks Free Tools  
**Difficulty:** Beginner  
**Status:** Completed

## 1. Project Overview

I successfully completed a hands-on PDF Password Cracking Challenge as part of my cybersecurity practical training with Networkwalks.

The exercise focused on recovering passwords from locked PDF documents using John the Ripper (JTR), a Hash Generator, and Networkwalks Free Tools.

This practical exercise helped me understand how password-protected PDF documents can be assessed, how password hashes are generated or extracted, and how password-cracking techniques can be used to test password strength.

## 2. Objectives

- Understand password protection in PDF documents.
- Learn how to generate or extract password hashes.
- Become familiar with John the Ripper (JTR).
- Practise dictionary-based password cracking.
- Understand the security risks associated with weak passwords.
- Explore practical document password security assessment.

## 3. Tools Used

| Tool | Purpose |
|---|---|
| John the Ripper (JTR) | Password hash testing and cracking |
| Hash Generator | Generating or extracting hash information |
| Networkwalks Free Tools | Supporting the PDF password-cracking exercise |

## 4. Practical Activities

During this challenge, I:

1. Worked with locked, password-protected PDF documents.
2. Used the Hash Generator to obtain the required hash information.
3. Prepared the hash for John the Ripper.
4. Used JTR to perform password-cracking operations.
5. Tested possible password combinations.
6. Reviewed the results and verified access to the protected PDF documents.

## 5. Key Learning Outcomes

This challenge strengthened my understanding of:

- PDF password protection.
- Password hash generation and extraction.
- John the Ripper and its practical applications.
- Dictionary-based password attacks.
- Password complexity and security.
- The importance of protecting confidential documents with strong passwords.

## 6. Ethical Considerations

All activities were conducted for educational purposes within an authorised training environment.

Password-cracking techniques should only be used on documents you own or have explicit permission to assess.
